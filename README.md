# lelila.ch – Webseite von Carolina Gigato

## Texte ändern

1. Gehe zu [github.com](https://github.com) und melde dich an
2. Öffne die Datei `index.html`
3. Klicke auf das **Stift-Symbol** (✏️) oben rechts
4. Ändere den Text – nur den Text zwischen `>` und `<` ändern, z.B.:
   ```
   <li>Energiearbeit</li>
   ```
   Hier kannst du "Energiearbeit" ändern, aber `<li>` und `</li>` stehen lassen.
5. Klicke auf **"Commit changes"** (grüner Knopf)
6. Die Webseite wird automatisch aktualisiert (ca. 1 Minute)
